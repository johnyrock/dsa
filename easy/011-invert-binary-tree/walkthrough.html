Invert Binary Tree, narrated

Scroll through mirroring a tree recursively, with the level-order state of the tree shown alongside.

Pattern used Tree post-order swap: invert both children, then swap them into each other's slot

STEP 1

The problem

Given the root of a binary tree, swap every node's left and right children, all the way down, and return the new root.

Running example: root = [4,2,7,1,3,6,9], a complete tree three levels deep. Inverted, it should read [4,7,2,9,6,3,1].

The output is the same tree object, mirrored in place — not a new tree.

STEP 2

First instinct: swap the top and stop

The obvious first move is root.left, root.right = root.right, root.left. That swaps the two subtrees at the top level — but the nodes inside those subtrees are untouched. 2's children (1 and 3) are still in their original left/right order, they just live under a different parent now.

Swapping only the top level fixes one level and silently leaves every level below it wrong.
STEP 3

The key idea: invert the children first

Mirroring has to happen at every node, not just the root. So: recursively invert the left subtree, recursively invert the right subtree, and only then swap the two (already-inverted) results into each other's slot.

Base case: an empty subtree mirrors to itself — None stays None, which also stops the recursion at leaves.

STEP 4

Trace it: node 7

Recursion reaches node 7 first among the right side. It has children 6 and 9, both leaves. Inverting each returns them unchanged, then 7 swaps them: left becomes 9, right becomes 6.

STEP 5

Trace it: node 2

Symmetrically, node 2's children 1 and 3 are leaves. After inverting each (no-ops) and swapping, 2's left is 3 and its right is 1.

STEP 6

Trace it: the root

Now the root's own call finishes: its left subtree (rooted at 2, already mirrored) and right subtree (rooted at 7, already mirrored) get swapped into each other's slot. Root's left becomes the mirrored 7-subtree, root's right becomes the mirrored 2-subtree.

Level order of the final tree: [4,7,2,9,6,3,1].
STEP 7

Where this goes wrong: swap order

Writing the swap as two separate statements is a common bug:

root.left = self.invert_tree(root.left)root.right = self.invert_tree(root.right)

That inverts each subtree in place but never swaps them — the tree is fully recursed but not mirrored. The swap has to be an explicit exchange of the two recursive results, done together.

STEP 8

Time and space

Every node is visited exactly once, doing O(1) work (one swap) at each — O(n) time. The only extra space is the call stack, which is as deep as the tree is tall: O(h), O(log n) for a balanced tree, O(n) for a skewed one.

STEP 9

The final solution

  • if root is None: return None — base case, also handles leaves.
  • Recurse on both children first, so the values being swapped are already fully mirrored.
  • Swap the two recursive results into root.left / root.right in one tuple assignment.
  • Return the same node, now mirrored.
One-line summary: invert both children, then swap the two inverted results into each other's slot.
