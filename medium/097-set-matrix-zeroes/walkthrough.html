Set Matrix Zeroes, narrated

Scroll through the thinking, from a full copy to two flag lists to storing the flags inside the first row and column, with the state of the matrix shown alongside.

Pattern used Matrix row 0 and column 0 double as the "zero this line" flags; two booleans remember their own fate

STEP 1

The problem

Given an m × n matrix, wherever there is a 0, set that cell's whole row and whole column to 0. Do it in place; the function returns nothing.

Running example: matrix = [[1,1,1],[1,0,1],[1,1,1]]. The single zero at (1, 1) clears row 1 and column 1, so the result is [[1,0,1],[0,0,0],[1,0,1]].

The subtlety is that only the original zeros count. The zeros we write while clearing row 1 must not then be treated as new triggers, or the cleared row would go on to clear every column it crosses and the whole matrix would end up zero. The answer keeps the four corner 1s.

The follow-up on LeetCode is the real question: the easy versions need O(m × n) or O(m + n) extra memory. Can it be done with O(1)?

STEP 2

First instinct: a copy, then two flag lists

The safest version reads from an untouched copy and writes into the original, so written zeros can never be mistaken for original ones:

snapshot = [row[:] for row in matrix]for r in range(rows):    for c in range(cols):        if snapshot[r][c] == 0:            for cc in range(cols): matrix[r][cc] = 0            for rr in range(rows): matrix[rr][c] = 0

That is O(m × n) extra space for the snapshot, and its inner loops make it O(m × n × (m + n)) time in the worst case. The obvious refinement: a zero at (r, c) only says two things, "row r goes" and "column c goes". Record those in zero_rows and zero_cols sets during one scan, then do a second scan that zeroes any cell whose row or column is in a set.

That is O(m × n) time and O(m + n) space. For the running example the sets are zero_rows = {1} and zero_cols = {1}. The only remaining question is where to keep those flags without allocating them.

STEP 3

The key insight: the flags can live in row 0 and column 0

The flag for row r needs one bit. The cell matrix[r][0] is already there, one per row. The flag for column c needs one bit, and matrix[0][c] is there, one per column. So: when an interior zero is found at (r, c), write 0 into matrix[r][0] and matrix[0][c].

Overwriting a header cell with 0 loses no information that matters. If the header cell was going to be zeroed anyway, fine. If it was not, its own row or column is being zeroed, so it becomes 0 regardless.

There is one catch. Row 0 and column 0 are now storage, so their own flags cannot be stored in themselves. Whether row 0 needs clearing and whether column 0 needs clearing are checked first and saved in two plain booleans, first_row_zero and first_col_zero, before any marking happens.

STEP 4

The approach: save, mark, apply, then finish the headers

  • first_row_zero = any(matrix[0][c] == 0 for c in range(cols)) and first_col_zero = any(matrix[r][0] == 0 for r in range(rows)) — remember the headers' fate before touching them.
  • Pass 1, over r in range(1, rows) and c in range(1, cols): if matrix[r][c] == 0: matrix[r][0] = 0; matrix[0][c] = 0 — set the flags.
  • Pass 2, same interior: if matrix[r][0] == 0 or matrix[0][c] == 0: matrix[r][c] = 0 — apply the flags.
  • if first_row_zero: zero all of row 0; if first_col_zero: zero all of column 0.

Both passes start at index 1, never 0. Pass 1 skipping the headers means only interior zeros set flags (the headers' own zeros are already captured in the booleans). Pass 2 skipping the headers means the flags are still intact while they are being read. The headers are cleared last, from the booleans, once nothing else needs them.

STEP 5

Trace it: save the booleans, then pass 1

Row 0 is 1, 1, 1 and column 0 is 1, 1, 1, so first_row_zero = False and first_col_zero = False. Neither header will be cleared at the end.

Pass 1 scans (1,1), (1,2), (2,1), (2,2). Only matrix[1][1] is 0. So matrix[1][0] = 0 (flag: row 1 goes) and matrix[0][1] = 0 (flag: column 1 goes). The matrix is now [[1,0,1],[0,0,1],[1,1,1]].

Those two written zeros sit in the header line, where pass 1 never looks, so they cannot trigger anything. Compare with the set version: zero_rows = {1} is exactly "matrix[1][0] is 0", and zero_cols = {1} is "matrix[0][1] is 0".

STEP 6

Trace it: pass 2 applies the flags

Same interior scan, now reading flags. (1,1): row flag matrix[1][0] is 0, so it is set to 0 (it already was). (1,2): row flag is 0, so matrix[1][2] = 0. (2,1): row flag matrix[2][0] is 1, but column flag matrix[0][1] is 0, so matrix[2][1] = 0. (2,2): row flag 1, column flag matrix[0][2] is 1, so it stays 1.

The matrix is [[1,0,1],[0,0,0],[1,0,1]]. The interior is finished, and the flags in the headers were read but never overwritten during this pass.

STEP 7

Trace it: the headers, and the answer

first_row_zero is False, so row 0 is left alone. Its 0 at (0, 1) stays, which is correct: column 1 was supposed to be zeroed, and that cell is in column 1. first_col_zero is False, so column 0 is left alone too, and its 0 at (1, 0) is right for the same reason.

Final matrix: [[1,0,1],[0,0,0],[1,0,1]], the expected output. The flag cells turned out to be exactly the cells the answer needed zeroed, which is the observation from step 3 in action.

Had the input been [[0,1,2,0],[3,4,5,2],[1,3,1,5]] instead, both booleans would be True (there is a 0 at (0,0)), and the two final loops would wipe row 0 and column 0, giving [[0,0,0,0],[0,4,5,0],[0,3,1,0]].
STEP 8

Where this goes wrong

Zeroing as you go. Scan the matrix and, on seeing a 0, immediately zero its row and column. The zeros you just wrote are then found later in the same scan. On the running example, (1,1) clears row 1 and column 1; the scan then reaches (1,2), now 0, and clears column 2; then (2,1), now 0, and clears row 2. Output: [[1,0,0],[0,0,0],[0,0,0]] instead of [[1,0,1],[0,0,0],[1,0,1]]. On a bigger matrix it cascades to all zeros.

One shared boolean for both headers. Using matrix[0][0] as the flag for row 0 and column 0 conflates two different facts. On [[1,2],[0,4]] the zero at (1,0) is in column 0, so the shared cell becomes 0 and row 0 gets wiped too: [[0,0],[0,0]] instead of [[0,2],[0,0]]. Two separate booleans, read before any marking, are required.

Clearing the headers before pass 2. If first_row_zero is applied between pass 1 and pass 2, every column flag reads 0 and the entire interior is zeroed. The header loops must be the last thing that runs.

Separate "find the triggers" from "apply them". Only original zeros are triggers; the flags are read only after all of them are written, and the flag storage is cleared last.
STEP 9

Time and space

Two full scans of the interior plus one pass each over row 0 and column 0: O(m × n) time. The only new storage is two booleans: O(1) space.

ApproachTimeExtra space
Snapshot copy, zero on sightO(m × n × (m + n))O(m × n)
Two flag sets, two passesO(m × n)O(m + n)
Flags in row 0 / column 0O(m × n)O(1)

The last two are the same algorithm; the only difference is where the flags live. Reaching for the in-matrix version is worth it when the interviewer asks for constant space, and knowing the flag-set version first makes the header bookkeeping much easier to explain.

STEP 10

The final solution

Nineteen lines. Every one of them maps to a step above.

  • first_row_zero / first_col_zero — the headers' own verdicts, saved before marking.
  • Pass 1 over the interior: if matrix[r][c] == 0: matrix[r][0] = 0; matrix[0][c] = 0 — write the flags.
  • Pass 2 over the interior: if matrix[r][0] == 0 or matrix[0][c] == 0: matrix[r][c] = 0 — apply the flags.
  • if first_row_zero: clear row 0; if first_col_zero: clear column 0 — last, from the booleans.
  • No return: the mutation is the result.
One-line summary to remember: save the headers' fate in two booleans, mark flags into row 0 / column 0, apply them to the interior, then clear the headers.
