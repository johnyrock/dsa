Clone Graph, narrated

Scroll through DFS with a visited-to-clone map, and why registering the clone before recursing is what makes cycles safe.

Pattern used Graph (DFS) original -> clone map both dedupes and breaks cycles

STEP 1

The problem

Given a node in a connected undirected graph, produce a full deep copy: new node objects, same values, same connections.

Running example: nodes 1, 2, 3, all pairwise connected (a triangle) — every edge is part of a cycle.
STEP 2

The key idea: map originals to clones as you go

DFS from the starting node, but before recursing into a node's neighbors, create its clone and register it in a map. Any later visit to the same original node — including one that arrives back via a cycle — finds the clone already there instead of recursing again.

STEP 3

Trace it: visit 1

dfs(1): not in clones. Create clone(1), register it. Now recurse into 1's neighbors: 2 and 3.

STEP 4

Trace it: visit 2

dfs(2): not in clones. Create clone(2), register it. Recurse into 2's neighbors: 1 and 3. dfs(1) now finds 1 already in clones — returns the existing clone(1) immediately, no infinite loop.

STEP 5

Trace it: visit 3, then unwind

dfs(3) similarly creates clone(3), and its recursive calls to dfs(1) and dfs(2) both hit the map and return immediately. Every original node now has exactly one clone, fully wired.

STEP 6

Where this goes wrong

Registering clones[n] = copy after the neighbor loop instead of before means the cycle back to n (via 2 -> 1) doesn't find it in the map yet, and recurses into dfs(1) again — and again — infinite recursion on any cycle, which an undirected graph always has (every edge is a 2-cycle).

STEP 7

Time and space

O(V + E) time — every node and edge visited once. O(V) space for the map plus recursion depth.

STEP 8

The final solution

  • Base case: None input returns None.
  • Map from original node to its clone, checked first in every call.
  • Register the clone before recursing into neighbors — this is what makes cycles safe.
  • Build each clone's neighbor list from the recursive results.
