Binary Tree Level Order Traversal, narrated

Scroll through a BFS queue, with each level's boundary drawn by snapshotting the queue length.

Pattern used Tree (BFS) queue processed one level at a time using a length snapshot

STEP 1

The problem

Group a binary tree's values level by level, left to right.

Running example: [3,9,20,null,null,15,7] -> [[3],[9,20],[15,7]].
STEP 2

The key idea: a queue naturally does BFS

A FIFO queue visits nodes in breadth-first order for free. The only missing piece is knowing where one level ends and the next begins.

Snapshot len(queue) before processing a level. That many pops belong to this level; anything pushed during those pops belongs to the next one.
STEP 3

Trace it: level 0

Queue starts as [3]. Snapshot length = 1. Pop 3, record it, push its children 9 and 20. Level result: [3].

STEP 4

Trace it: level 1

Queue is now [9, 20]. Snapshot length = 2. Pop 9 (no children), pop 20 (push 15, 7). Level result: [9, 20].

STEP 5

Trace it: level 2

Queue is now [15, 7]. Snapshot length = 2. Pop both, neither has children. Level result: [15, 7]. Queue is empty, loop ends.

STEP 6

Where this goes wrong

Writing for _ in range(len(queue)) is safe because Python evaluates len(queue) once, at the start of the loop. But if you instead write a manual while that re-checks len(queue) every iteration, pushes during the loop change the bound and merge two levels together.

STEP 7

Time and space

Every node is enqueued and dequeued exactly once — O(n) time. The queue can hold up to ~n/2 nodes at once (the widest level) — O(n) space.

STEP 8

The final solution

  • root is None returns [] immediately.
  • Seed the queue with the root.
  • Snapshot the queue's length before each level's inner loop.
  • Push children as nodes are popped; they become next level's work.
