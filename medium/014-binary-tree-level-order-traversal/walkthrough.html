Binary Tree Level Order Traversal, narrated

I’ll start by collecting one depth at a time with repeated DFS passes, then let a queue expose each level in one traversal.

Pattern used Tree (BFS) queue processed one level at a time using a length snapshot

STEP 1

The problem

Group a binary tree's values level by level, left to right.

Running example: [3,9,20,null,null,15,7] -> [[3],[9,20],[15,7]].
STEP 2

First instinct: run DFS once per depth

My first instinct finds the tree height, then runs a depth-limited DFS for every level and collects the nodes at that depth.

def height(node):    return 0 if not node else 1 + max(height(node.left), height(node.right))result = []for depth in range(height(root)):    level = []    def collect(node, d):        if not node: return        if d == depth: level.append(node.val); return        collect(node.left, d + 1); collect(node.right, d + 1)    collect(root, 0); result.append(level)return result

Rewalking the tree for every depth takes O(n · h) time, and the recursion stack plus output uses O(n) space.

A queue already visits nodes by depth in one pass. I snapshot its length before each level so I know exactly where that level ends.

STEP 3

Trace it: level 0

I start with queue [3] and snapshot length 1. I pop 3, record it, and push children 9 and 20. The level result is [3].

STEP 4

Trace it: level 1

My queue is now [9, 20], so I snapshot length 2. I pop 9 with no children, then pop 20 and push 15 and 7. The level result is [9, 20].

STEP 5

Trace it: level 2

My queue is now [15, 7], so I snapshot length 2. I pop both nodes and find no children. The level result is [15, 7], and the empty queue ends the loop.

STEP 6

Where this goes wrong

I use for _ in range(len(queue)) because Python evaluates len(queue) once, at the start of the loop. A manual while that re-checks len(queue) every iteration changes its bound as children are pushed and merges two levels together.

STEP 7

Time and space

Every node is enqueued and dequeued exactly once — O(n) time. The queue can hold up to ~n/2 nodes at once (the widest level) — O(n) space.

STEP 8

The final solution

  • root is None returns [] immediately.
  • queue = deque([root]) seeds the queue with the root.
  • for _ in range(len(queue)) snapshots one level’s boundary.
  • queue.popleft() visits each node while child appends become next level’s work.
