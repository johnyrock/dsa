Longest Substring Without Repeating Characters, narrated

Scroll through the thinking, from checking every substring to a sliding window whose left edge jumps straight past the repeat, with the state of the algorithm shown alongside.

STEP 1

The problem

You get a string. Find the length of the longest contiguous stretch in which no character appears twice.

Only the length is asked for, not the substring itself, and contiguity is the whole game: "pwke" is not an answer for "pwwkew" because those letters are not next to each other.

Running example: s = "abcabcbb". The answer is 3, from "abc" (and "bca" and "cab", which tie).
STEP 2

First instinct: check every substring

Try every start index and every end index, and for each pair check whether the characters in between are all distinct.

best = 0for i in range(len(s)):    seen = set()    for j in range(i, len(s)):        if s[j] in seen: break        seen.add(s[j])        best = max(best, j - i + 1)

This version already breaks out of the inner loop at the first repeat, which makes it O(n²) rather than O(n³). At n = 50,000 that can still be over a billion steps.

The waste: after finding that s[i..j] has a repeat, we restart from i+1 and re-examine almost the same characters.

STEP 3

Reframe: keep one window and slide it

Hold a window s[left..right] that is always free of repeats. Push right forward one character at a time. Most of the time the new character is new to the window and the window just grows.

When the new character already lives inside the window, the window is broken at exactly one place: the earlier copy. Move left to just past that copy and the window is valid again.

Every valid window has to end somewhere. For each right, the window we hold is the longest valid one ending there, so checking its length at each step finds the overall best.
STEP 4

The key idea: remember where each character was last seen

To move left past the earlier copy, we need to know where the earlier copy is. A dictionary last_seen[ch] = index answers that in O(1), and it lets left jump rather than crawl.

  • If ch is in last_seen and that index is at or after left, the copy is inside the window: set left = last_seen[ch] + 1.
  • Record last_seen[ch] = right either way.
  • Then right - left + 1 is a valid length; keep the max.

The condition >= left is not decoration. It is the difference between a right and a wrong answer, as Step 7 shows.

STEP 5

Trace it: the window grows to "abc"

right = 0: a is new. Window "a", length 1. right = 1: b is new. Window "ab", length 2. right = 2: c is new. Window "abc", length 3.

best is now 3 and last_seen holds a → 0, b → 1, c → 2. Nothing has been thrown out yet.

STEP 6

Trace it: the first repeat

right = 3, character a. last_seen[a] = 0, and 0 >= left = 0, so the old a is inside the window. Jump left to 1.

The window is now "bca", still length 3. Update last_seen[a] = 3. best stays at 3.

The next few steps do the same dance: b at 4 pushes left to 2, c at 5 pushes it to 3, b at 6 pushes it to 5, and the final b at 7 pushes it to 7. Each window is at most 3 wide, so the answer is 3.

STEP 7

The pitfall: a stale occurrence outside the window

Take s = "abba". After the two bs, left is 2 and the window is "b". Now the final a arrives. last_seen[a] = 0, but that a was cut out of the window long ago.

Without the >= left check, left would be set to 1, moving backwards, and the "window" "bba" would be reported with length 3. The right answer is 2.

Only jump when the previous occurrence is at or after left. Equivalently, left = max(left, last_seen[ch] + 1). Either form keeps left moving one way only.

STEP 8

Time and space

right advances n times. left only ever moves forward, so across the whole run it moves at most n times too. Everything else is O(1) dictionary work. O(n) time.

The dictionary has one entry per distinct character, so O(min(n, alphabet size)) space: at most 128 entries for ASCII no matter how long the string is.

ApproachTimeSpace
Every substring, with early breakO(n²)O(alphabet)
Window with a set, crawl left forwardO(n)O(alphabet)
Window with last-seen index, jump leftO(n)O(alphabet)
STEP 9

The final solution

Nine lines. Every one of them maps to a step above.

  • last_seen = {} is the char-to-index memory that lets left jump.
  • left = 0 and best = 0 start an empty window; the empty string returns 0 untouched.
  • for right, ch in enumerate(s) is the single forward pass.
  • if ch in last_seen and last_seen[ch] >= left asks "is the repeat inside the window?"
  • left = last_seen[ch] + 1 is the jump.
  • best = max(best, right - left + 1) measures the now-valid window.
One-line summary to remember: grow the right edge; on a repeat inside the window, jump the left edge past the old copy.
