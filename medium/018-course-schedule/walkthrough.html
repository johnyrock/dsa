Medium · Topological Sort · LeetCode #207

Course Schedule, narrated

Scroll through Kahn's algorithm: take courses with zero prerequisites left, and watch cycles reveal themselves as courses that never reach zero.

Pattern used Topological Sort BFS with indegree counts (Kahn's algorithm); a cycle leaves nodes permanently stuck at indegree > 0

STEP 1

The problem

Given prerequisite pairs, decide whether it's possible to take every course. Impossible exactly when the prerequisites form a cycle.

Running example: 4 courses, edges 0->1, 0->2, 1->3, 2->3 (a diamond). No cycle, so it should return True.
STEP 2

The key idea: peel off zero-indegree courses

Build the graph and count each course's indegree (unmet prerequisites). Any course with indegree 0 can be taken right now. Taking it removes one prerequisite from everything it unlocks — if that drops a course to indegree 0, it becomes takeable too.

STEP 3

Trace it: seed the queue

Indegrees: 0:0, 1:1, 2:1, 3:2. Only course 0 starts at indegree 0 — queue = [0].

STEP 4

Trace it: take course 0

Pop 0, taken=1. It unlocks 1 and 2: their indegrees drop to 0 each. Queue = [1, 2].

STEP 5

Trace it: take 1, then 2

Pop 1, taken=2, course 3's indegree drops from 2 to 1 (not yet 0). Pop 2, taken=3, course 3's indegree drops to 0 — queue = [3].

STEP 6

Trace it: take course 3

Pop 3, taken=4. Queue is empty. taken == num_courses (4 == 4) -> True.

STEP 7

Contrast: a cycle

With edges 0->1, 1->0: both start at indegree 1, neither ever reaches 0, the queue starts empty, taken stays 0. 0 == 2 is False — correctly detected without any explicit cycle search.

STEP 8

Where this goes wrong

Building the edge as a -> b for a pair [a, b] instead of b -> a reverses the whole dependency direction. [a, b] means b must be taken before a, so the edge (b unlocks a) is b -> a.

STEP 9

Time and space

O(V + E) time and space — every course and every prerequisite edge is processed once.

STEP 10

The final solution

  • Build the graph and indegree counts.
  • Seed the queue with every indegree-0 course.
  • Pop, count it as taken, decrement its neighbors' indegree, enqueue any that hit 0.
  • All courses taken iff there was no cycle.
