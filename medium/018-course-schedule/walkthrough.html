Medium · Topological Sort · LeetCode #207

Course Schedule, narrated

I’ll start with a recursive cycle search, then I process courses with zero prerequisites left using Kahn’s queue.

Pattern used Topological Sort BFS with indegree counts (Kahn's algorithm); a cycle leaves nodes permanently stuck at indegree > 0

STEP 1

The problem

Given prerequisite pairs, decide whether it's possible to take every course. Impossible exactly when the prerequisites form a cycle.

Running example: 4 courses, edges 0->1, 0->2, 1->3, 2->3 (a diamond). No cycle, so it should return True.
STEP 2

First instinct: DFS with visiting states

I build the prerequisite graph and use DFS states to catch a back edge into a course already on my recursion path.

state = [0] * num_coursesdef visit(course):    if state[course] == 1: return False    if state[course] == 2: return True    state[course] = 1    if not all(visit(pre) for pre in graph[course]): return False    state[course] = 2; return Truereturn all(visit(course) for course in range(num_courses))

This touches each vertex and edge in O(V + E) time; the state array and recursion stack take O(V) extra space.

For the next view, I track prerequisite removal with indegrees. A queue makes every newly available course visible and leaves cycle members stuck above zero.

STEP 3

Trace it: seed the queue

Indegrees: 0:0, 1:1, 2:1, 3:2. Only course 0 starts at indegree 0 — queue = [0].

STEP 4

Trace it: take course 0

I pop 0, taken=1. It unlocks 1 and 2: their indegrees drop to 0 each. Queue = [1, 2].

STEP 5

Trace it: take 1, then 2

I pop 1, taken=2, course 3's indegree drops from 2 to 1 (not yet 0). I pop 2, taken=3, course 3's indegree drops to 0 — queue = [3].

STEP 6

Trace it: take course 3

I pop 3, taken=4. Queue is empty. taken == num_courses (4 == 4) -> True.

STEP 7

Contrast: a cycle

With edges 0->1, 1->0: both start at indegree 1, neither ever reaches 0, the queue starts empty, taken stays 0. 0 == 2 is False — correctly detected without any explicit cycle search.

STEP 8

Where this goes wrong

Building the edge as a -> b for a pair [a, b] instead of b -> a reverses the whole dependency direction. [a, b] means b must be taken before a, so the edge (b unlocks a) is b -> a.

STEP 9

Time and space

O(V + E) time and space — every course and every prerequisite edge is processed once.

STEP 10

The final solution

I build graph[pre].append(course) and increment indegree[course] for every prerequisite pair. Then deque(...) starts with every zero-indegree course.

  • course = queue.popleft() takes one available course.
  • taken += 1 records its completion.
  • indegree[nxt] -= 1 removes its prerequisite edge.
  • if indegree[nxt] == 0 makes a newly available course enter the queue.
  • return taken == num_courses rejects any cycle.
