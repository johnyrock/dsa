House Robber II, narrated

Scroll through the thinking, from the linear robber that quietly breaks on a ring to two passes that each leave one end house alone, with the state of the algorithm shown alongside.

Pattern used Dynamic Programming rob the line twice, once without the first house and once without the last, keep the larger

STEP 1

The problem

Houses stand in a circle. nums[i] is the money in house i, and every house is wired to both neighbours, so robbing two adjacent houses trips the alarm. Because of the circle, the first and last houses are neighbours too.

Return the most money you can take without ever robbing two houses that touch.

Running example: nums = [2, 3, 2]. The answer is 3. On a straight street you would grab both 2s for 4, but house 0 and house 2 are next to each other on the ring, so the best legal haul is the single 3.

Everything about this problem is the ordinary House Robber except one extra wire: the one that joins house n − 1 back to house 0.

STEP 2

First instinct: try every subset of houses

Enumerate every subset of houses, throw out the ones with two neighbours (including the wrap-around pair), and keep the richest survivor.

best = 0for mask in range(1 << n):    chosen = [i for i in range(n) if mask >> i & 1]    if all((i + 1) % n not in chosen for i in chosen):        best = max(best, sum(nums[i] for i in chosen))

There are 2ⁿ subsets, and checking each takes O(n): O(n · 2ⁿ). At the constraint limit of 100 houses that is astronomically many masks. It does at least state the rule precisely: the neighbour of house i is (i + 1) % n, and the modulo is what makes house n − 1 touch house 0.

STEP 3

Reframe: the ring only adds one rule

Suppose you already know how to rob a straight line of houses. skip is the best loot so far if the previous house was not robbed; take is the best loot so far, full stop. Each new house either joins the plan (skip + money) or stays out (take), and the pair rolls forward.

The ring breaks that only at one seam. Run the linear robber on [2, 3, 2] and it happily takes house 0 and house 2 for 4, never noticing that they touch.

The circle forbids exactly one thing the line allows: robbing house 0 and house n − 1 together. Every other constraint is already handled by the line.
STEP 4

The key idea: two lines, one answer

Any legal plan on the ring either leaves house 0 alone or leaves house n − 1 alone (it might leave both). So split into two cases:

  • House 0 is not robbed. Then the remaining houses nums[1:] form a plain line: house 1 through house n − 1, with nothing wrapping around.
  • House n − 1 is not robbed. Then nums[:-1] is a plain line from house 0 to house n − 2.

Solve each line with the linear robber, _rob_line, and return max(...) of the two. A plan that leaves both ends alone is counted by both passes, which is harmless for a max.

The one input this split cannot handle is a single house: nums[1:] and nums[:-1] are both empty, so the guard if len(nums) == 1: return nums[0] comes first.

STEP 5

Trace it: pass 1, drop house 0, rob [3, 2]

Start with skip = 0, take = 0. House 1 has 3: take = max(0, 0 + 3) = 3, and the old take, 0, becomes the new skip.

House 2 has 2: robbing it means the previous house was skipped, so it is worth skip + 2 = 0 + 2 = 2. Not robbing it keeps take = 3. max(3, 2) = 3, and skip becomes 3.

Pass 1 returns 3: with house 0 off the table, the 3 alone beats the lone 2.

STEP 6

Trace it: pass 2, drop house 2, rob [2, 3]

Fresh variables, skip = 0, take = 0. House 0 has 2: take = max(0, 0 + 2) = 2, skip = 0.

House 1 has 3: robbing it is worth skip + 3 = 0 + 3 = 3, keeping the plan is worth take = 2. max(2, 3) = 3, and skip becomes 2.

Pass 2 also returns 3. Two different lines, two different plans (the 3 on its own in both, as it happens), but neither was ever allowed to pair the two 2s.

STEP 7

Trace it: combine

max(3, 3) = 3. That is the answer, and it is the value the panel shows in green.

Compare with the linear robber on the whole ring, which would have continued from pass 2's state: house 2 is worth skip + 2 = 2 + 2 = 4, beating take = 3. That 4 is the illegal plan that robs both end houses. Splitting into two lines is what makes that plan impossible to express.

The linear robber is called twice on n − 1 houses each. Nothing about the recurrence changed; only the input did.
STEP 8

Where this goes wrong: the seam and the single house

Running the line once over the whole ring. return self._rob_line(nums) on [2, 3, 2] returns 4, not 3: it robs houses 0 and 2, which are neighbours across the seam. The panel shows that state, with both end houses lit and the alarm tripped.

Forgetting the single-house guard. Without if len(nums) == 1, the input [1] produces two empty slices, each pass returns 0, and the function answers 0 instead of 1.

Splitting the tuple assignment. Writing skip = take on one line and take = max(take, skip + money) on the next means the second line reads the freshly updated skip, so the robber is allowed to take neighbours. On the whole array [2, 3, 2] that yields 7.

The ring adds exactly one forbidden pair, house 0 with house n − 1. Handle it by never letting both into the same pass, and remember the one input where both passes are empty.
STEP 9

Time and space

Two passes, each a single loop over n − 1 houses with two integers of state: O(n) time. The slices copy the array, so as written it is O(n) extra space; pass index bounds into _rob_line instead and it is O(1).

ApproachTimeSpace
Every subset, filter neighboursO(n · 2ⁿ)O(n)
Full dp table per passO(n)O(n)
Two rolling variables, two passesO(n)O(1) with index bounds

The circle costs a constant factor of two, nothing more.

STEP 10

The final solution

Ten lines. Every one of them maps to a step above.

  • if len(nums) == 1: return nums[0] handles the only input where both slices are empty.
  • max(self._rob_line(nums[1:]), self._rob_line(nums[:-1])) tries the ring with house 0 excluded and with house n − 1 excluded.
  • skip, take = 0, 0 seeds the linear robber before any house.
  • skip, take = take, max(take, skip + money) is the recurrence and the slide in one statement: rob this house on top of the plan that skipped the previous one, or keep the previous plan.
  • return take is the best loot for that line.
One-line summary to remember: a ring is two lines, one without the first house and one without the last; rob each and keep the larger.
