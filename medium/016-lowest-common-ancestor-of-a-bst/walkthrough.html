Lowest Common Ancestor of a BST, narrated

I’ll start with the general recursive LCA search, then I use BST ordering to walk only the subtree that can contain both targets.

Pattern used Tree walk down; the split point where p and q stop sharing a side is the LCA

STEP 1

The problem

Given a BST and two of its nodes p and q, find their lowest common ancestor.

Running example: root 6, p = 2, q = 8.
STEP 2

First instinct: search both subtrees

I begin with the general binary-tree LCA recursion: I find each target below the current node and return the first node where those searches split.

def lca(node, p, q):    if not node or node is p or node is q: return node    left = lca(node.left, p, q)    right = lca(node.right, p, q)    if left and right: return node    return left or rightreturn lca(root, p, q)

That recursion may visit the whole tree, so it takes O(n) time and uses O(h) extra space for recursion.

The BST ordering saves that wasted search. When both targets sit on one side of a node, I discard the other subtree immediately.

STEP 3

Trace it: p=2, q=8, start at root 6

2 < 6 and 8 > 6 — not both smaller, not both larger. This is the split. I return 6.

STEP 4

Trace it: p=2, q=4, start at root 6

Both 2 and 4 are < 6, go left to node 2. Now 2 == node.val (p is the node itself) and 4 > 2 — not both smaller, not both larger. I return 2.

STEP 5

Trace it: p=3, q=5, start at root 6

Both < 6, go left to 2. Both > 2, go right to 4. Now 3 < 4 and 5 > 4 — split found. I return 4.

STEP 6

Where this goes wrong

Using non-strict comparisons (<=/>=) for the branch conditions would keep walking past the node where one target equals the current value, potentially descending past the actual LCA. Strict comparisons correctly fall into the else-branch the moment one target matches or the two diverge.

STEP 7

Time and space

Each step descends one level — O(h) time, O(1) extra space iteratively.

STEP 8

The final solution

I start with node = root and keep walking while node exists. The left branch is p.val < node.val and q.val < node.val, followed by node = node.left. The right branch is p.val > node.val and q.val > node.val, followed by node = node.right.

  • while node keeps the walk on one root-to-leaf path.
  • if handles the both-left case.
  • elif handles the both-right case after both-left fails.
  • return node returns the first split point.
  • return None covers an impossible missing-target case.
When neither same-side condition holds, node is between the targets or equals one of them, so I return node as the LCA.
