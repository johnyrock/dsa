Medium · Greedy · LeetCode #134

Gas Station, narrated

I follow one running fuel balance, using each failure to discard every start that would fail even sooner.

Pattern used Greedy running dry at i rules out every start up to i, so restart at i + 1 with an empty tank

STEP 1

The problem

There are n gas stations on a circle. At station i you can take on gas[i] litres, and driving from station i to station i + 1 (wrapping from the last back to the first) burns cost[i] litres. You pick a station, start with an empty tank, fill up there, and drive clockwise.

Return the index of the unique station from which you can complete the full circle, or -1 if there is none.

Running example: gas = [1,2,3,4,5], cost = [3,4,5,1,2]. The answer is 3. Starting there the tank reads 4 − 1 = 3, then 3 + 5 − 2 = 6, then 6 + 1 − 3 = 4, then 4 + 2 − 4 = 2, then 2 + 3 − 5 = 0, back at station 3 with exactly nothing to spare.

The useful quantity is the net change per leg, gas[i] - cost[i]: here [-2, -2, -2, 3, 3]. The tank must never go below zero at any point of the trip, and that constraint is what kills most starting points.

STEP 2

First instinct: simulate every start

My first instinct is to try each station as a start and drive the whole circle, stopping early whenever my tank goes negative.

for start in range(n):    tank = 0    for k in range(n):        i = (start + k) % n        tank += gas[i] - cost[i]        if tank < 0:            break    else:        return startreturn -1

On the example, starts 0, 1, and 2 fail immediately, while start 3 survives all five legs. This is O(n²) time in the worst case and O(1) extra space.

The simulations overlap. When I try start 3, I re-drive legs that earlier attempts already measured, even though one failure can rule out several starts.

STEP 3

The key insight: a failure rules out a whole stretch

If I leave station s and the tank first goes negative on the leg out of station i, no station between s and i can be the answer either. I reached each of those stations with fuel >= 0, so starting there with an empty tank puts me in a strictly worse position on the same legs and I die at i at the latest.

So the next candidate is i + 1, with tank = 0. Every station is examined once as a candidate or skipped in one go.

The second fact closes the loop. The single pass only drives from the candidate to the end of the array, never wrapping around. It is enough because sum(gas) >= sum(cost) guarantees some start works, and the pass has eliminated every station except the survivor. If the totals fail, no start can work at all, and that check comes first.

STEP 4

The approach

  • if sum(gas) < sum(cost): return -1: the circle burns more than it provides; nobody finishes.
  • start = 0, tank = 0: assume station 0 until proven otherwise.
  • for i in range(len(gas)): drive each leg once.
  • tank += gas[i] - cost[i]: I fill up and drive to the next station.
  • if tank < 0: the candidate died on this leg, so start = i + 1 and tank = 0.
  • return start: the last candidate never went negative, and the total check covers the wrap.

In the panel the blue cell is the current leg, green cells are legs the current candidate has survived, and dimmed cells are stations already ruled out.

STEP 5

Trace it: leg 0

I first check sum(gas) = 15 and sum(cost) = 15, so a solution exists and I continue.

i = 0: tank = 0 + (1 - 3) = -2. It is negative, so station 0 is out. I set start = 1 and tank = 0.

Only one station was ruled out here, because the candidate died on its very first leg. The elimination gets more powerful when a candidate lasts a few legs before failing.

STEP 6

Trace it: legs 1 and 2

i = 1: tank = 0 + (2 - 4) = -2. Station 1 dies immediately as well: start = 2, tank = 0.

i = 2: tank = 0 + (3 - 5) = -2. Station 2 dies: start = 3, tank = 0.

Three legs driven, three candidates eliminated, and the pass has never gone back to re-drive anything. Stations 0, 1, 2 are dimmed for good.

STEP 7

Trace it: legs 3 and 4

i = 3: tank = 0 + (4 - 1) = 3. Positive, so station 3 survives its first leg.

i = 4: tank = 3 + (5 - 2) = 6. Still positive, and the array is finished. The loop exits with start = 3.

I never drive the wrap-around legs 0, 1, 2 from station 3. The totals balance, so the 6 litres in hand exactly cover the -2 -2 -2 those legs cost. return 3.
STEP 8

Where this goes wrong: the reset and the total check

Resetting to start = i. It feels natural to try the station where the tank died. But i is the station I ran dry leaving; I filled up there and it was not enough, so it cannot be the start. On the example the last reset happens at i = 2 and the function returns 2 instead of 3. The next candidate is i + 1.

Skipping the sum(gas) < sum(cost) check. My sweep never wraps, so it always ends with some start in hand. On gas = [2,3,4], cost = [3,4,3] the net legs are [-1, -1, 1]; the sweep resets twice and returns 2, but total gas 9 is less than total cost 10 and the correct answer is -1. The greedy pass proves “nobody else,” while the total check proves somebody exists; I need both.

Forgetting tank = 0 on reset. The deficit leaks into the next candidate. On the example the tank runs −2, −4, −6, −3, 0, so the reset also fires at i = 3 and the answer comes out as 4.

When I fail at i, my candidate becomes i + 1 and my tank becomes 0. Before the sweep, I compare the totals.
STEP 9

Time and space

Two sums and one sweep, each a single pass: O(n) time. Two integers of state: O(1) space.

ApproachTimeSpace
Simulate every startO(n²)O(1)
Prefix sums of net fuel, pick the start after the minimumO(n)O(n)
Greedy reset (this solution)O(n)O(1)

The prefix-sum version is the same idea seen from a different angle: the valid start is the station right after the lowest point of the running total, which is exactly where the last reset lands.

STEP 10

The final solution

  • if sum(gas) < sum(cost): return -1 settles existence before any driving.
  • start = 0, tank = 0 seed the first candidate with an empty tank.
  • tank += gas[i] - cost[i] drives one leg.
  • if tank < 0: start = i + 1; tank = 0 discards the candidate and every station up to i in one move.
  • return start is the only station the pass could not eliminate.
One-line summary to remember: if the totals balance a start exists; sweep once and restart at i + 1 every time the tank dips below zero, and the last restart is the answer.
