Product of Array Except Self, narrated

Scroll through the thinking, from the nested loop through the division trick that breaks on zeros to the two-sweep prefix and suffix products, with the state of the algorithm shown alongside.

Pattern used Prefix Sum left products in one sweep, right products multiplied on top, no division

STEP 1

The problem

You get an array nums. Build a new array where slot i holds the product of every element except nums[i].

Two rules make it interesting: you may not use division, and the solution must run in O(n).

Running example: nums = [1, 2, 3, 4]. The answer is [24, 12, 8, 6]. Slot 0 is 2·3·4, slot 1 is 1·3·4, and so on.

The "no division" rule is not arbitrary. It is there to rule out one specific shortcut, and to make you find the pattern that also survives zeros.

STEP 2

First instinct: multiply everything else, per slot

For each index i, loop over the whole array and multiply together every element whose index is not i.

result = []for i in range(len(nums)):    p = 1    for j in range(len(nums)):        if j != i:            p *= nums[j]    result.append(p)

Correct, and it needs no division. But each slot rescans the whole array, so it is O(n²). At n = 100,000 that is ten billion multiplications, and the statement demands O(n).

STEP 3

The tempting shortcut, and why it is banned

Compute the product of everything once, then each slot is total / nums[i]. One pass, O(n). Except the problem forbids division, and there is a real reason: zeros.

With nums = [-1, 1, 0, -3, 3] the total is 0, and dividing by nums[2] = 0 is undefined. You can patch it by counting zeros: one zero means only that slot is non-zero, two or more means everything is zero. It works, but it is three special cases stacked on a trick.

Division is not a building block here. It is a way of undoing a multiplication you did not need to do. The clean solution never multiplies nums[i] into its own answer in the first place.
STEP 4

Reframe: split "everything else" into left and right

Everything except nums[i] is exactly two pieces: everything to the left of i, and everything to the right. The answer for slot i is the product of those two pieces.

For i = 2 in the example, the left piece is 1·2 = 2 and the right piece is 4, so the answer is 2·4 = 8. Neither piece involves nums[2], so nothing needs to be divided back out.

Both pieces are running products. The left product for slot i+1 is the left product for slot i times nums[i]. Same for the right, going the other way.

That means one sweep left to right produces every left piece, and one sweep right to left produces every right piece.

STEP 5

Sweep 1: prefix products, stored in the output

Start prefix = 1, the product of nothing. At each index, first write the current prefix into result[i], and only then multiply nums[i] into prefix. The order matters: slot i must see the product of what came before it, not including itself.

After the sweep, result is [1, 1, 2, 6]: the product of the empty left side, then 1, then 1·2, then 1·2·3.

STEP 6

Sweep 2: suffix products, multiplied on top

Now walk from the right end with suffix = 1. At each index, multiply result[i] by suffix, then fold nums[i] into suffix for the slots further left.

Slot 3 gets 6·1 = 6. Slot 2 gets 2·4 = 8. Slot 1 gets 1·12 = 12. Slot 0 gets 1·24 = 24. Each slot ends up as left product times right product, which is everything except itself.

The output array was the only storage. No prefix array, no suffix array, no division, two passes.
STEP 7

Zeros fall out for free

Run the same two sweeps on [-1, 1, 0, -3, 3]. The prefix products are [1, -1, -1, 0, 0]: once the zero has been folded in, every later prefix is 0. The suffix products, read left to right, are [0, 0, -9, 3, 1]: every slot left of the zero has a 0 on its right.

Multiply them slot by slot and only index 2, the zero itself, survives: −1 · −9 = 9. Everything else is 0, exactly the expected [0, 0, 9, 0, 0].

No zero counting, no special cases. Because nums[i] was never multiplied into its own slot, there was nothing to undo.

STEP 8

Time and space

Two passes over n elements with O(1) work each: O(n) time.

Two scalars plus the output array. The statement does not count the output, so this is O(1) extra space. A first version with separate left[] and right[] arrays is O(n) extra and is a fine stepping stone.

ApproachTimeExtra space
Nested loopO(n²)O(1)
Total / nums[i] with zero handlingO(n)O(1), but uses division
Prefix and suffix arraysO(n)O(n)
Two sweeps into the outputO(n)O(1)
STEP 9

The final solution

Twelve lines. Every one of them maps to a step above.

  • result = [1] * n is the output doubling as scratch space, seeded with the multiplicative identity.
  • The first loop writes prefix before folding in nums[i], so a slot never includes itself.
  • The second loop runs n-1 down to 0 and multiplies suffix on top, again before folding in nums[i].
  • return result hands back left × right for every slot.
One-line summary to remember: everything except me is everything on my left times everything on my right.
