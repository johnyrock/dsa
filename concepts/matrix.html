Matrix Manipulation, Explained

Rotating, spiralling, and zeroing a grid in place: describe the state with a few bounds and flags instead of copying cells.

The core idea

A matrix is just a list of lists, but the interesting problems ask you to change it in place: turn it a quarter turn, walk it in a spiral, wipe out rows and columns, all without allocating a second grid. The trick every time is the same. Find a small number of coordinates, bounds, or flags that describe the state, and update those instead of copying cells around.

Three ideas cover most of it. A rotation is a transpose followed by a reverse. A spiral is four bounds that shrink inward. And when you need to remember something about every row and column but have no spare memory, row 0 and column 0 are your notebook.

Why it's fast: every cell is touched a constant number of times and nothing is copied. Time is O(rows × cols), which you cannot beat since you have to look at every cell, and extra space is O(1).

How to recognise it

Reach for these tricks when a problem says, or quietly implies, one of these:

  • "In place" or "O(1) extra space" on a 2-D input. That is the signal to store state in the grid itself.
  • The output order is geometric: rotated, spiral, layer by layer, diagonal. You are not searching the grid, you are walking it in a fixed shape.
  • Whole rows or columns change together. The answer depends on "does this row contain X" rather than on the neighbours of each cell.
  • No visited set, no neighbours. If the question is about reachability or connectivity, that is graph traversal, not this page.

The naive way first

Take this problem: rotate an n × n image 90 degrees clockwise, in place. The instinctive answer is to build the rotated grid and copy it back: 

def rotate_slow(matrix):
    n = len(matrix)
    rotated = [[0] * n for _ in range(n)]
    for r in range(n):
        for c in range(n):
            rotated[c][n - 1 - r] = matrix[r][c]   # (r, c) lands at (c, n-1-r)
    for r in range(n):
        matrix[r] = rotated[r]

This works, and the index formula is even correct, but it uses a second n × n grid, which is exactly what "in place" forbids. The next thought is usually to move cells around in cycles of four, which is right but fiddly. There is a cleaner way to get the same result with two simple passes.

The pattern

A clockwise rotation is a transpose (flip across the main diagonal) followed by reversing each row.

def rotate(matrix):
    n = len(matrix)
    # 1. transpose: swap (r, c) with (c, r), but only above the diagonal
    for r in range(n):
        for c in range(r + 1, n):
            matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
    # 2. reverse every row
    for row in matrix:
        row.reverse()

The line that matters is range(r + 1, n). Transposing means swapping every pair across the diagonal exactly once. If you loop over the whole square you swap each pair twice and end up where you started.

The same "describe, don't copy" mindset gives you the spiral walk. Keep four bounds, top, bottom, left, right, walk the top row, then the right column, then the bottom row backwards, then the left column upwards, and pull each bound in by one after its side is done. 

def spiral(matrix):
    out = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for c in range(left, right + 1):
            out.append(matrix[top][c])
        top += 1
        for r in range(top, bottom + 1):
            out.append(matrix[r][right])
        right -= 1
        if top <= bottom:                      # a single row may be all that is left
            for c in range(right, left - 1, -1):
                out.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:                      # a single column may be all that is left
            for r in range(bottom, top - 1, -1):
                out.append(matrix[r][left])
            left += 1
    return out

Variations

Counter-clockwise, and the other flips

Transpose then reverse each column (or reverse each row first, then transpose) rotates counter-clockwise. Reversing rows alone is a horizontal mirror; reversing the row order alone is a vertical mirror. Any rotation or reflection of a square is one or two of these primitives.

Spiral bounds for a non-square grid

The two if guards in the spiral are the whole difficulty. Picture a 3 × 1 column: after the top row (one cell) and the right column (two cells) you have consumed everything, but without the guards the bottom-row loop would walk that same cell again. Check top <= bottom before the bottom row and left <= right before the left column.

Borders as flags (Set Matrix Zeroes)

"If a cell is 0, set its whole row and column to 0." The obvious plan keeps a set of rows and a set of columns, which is O(rows + cols) space. To get to O(1), use the first row as the column flags and the first column as the row flags. The only wrinkle is that those two lines share the corner cell, so you save whether row 0 and column 0 originally contained a zero in two plain booleans before you start writing. 

def set_zeroes(matrix):
    rows, cols = len(matrix), len(matrix[0])
    row0 = any(matrix[0][c] == 0 for c in range(cols))
    col0 = any(matrix[r][0] == 0 for r in range(rows))

    for r in range(1, rows):                 # pass 1: record
        for c in range(1, cols):
            if matrix[r][c] == 0:
                matrix[r][0] = matrix[0][c] = 0

    for r in range(1, rows):                 # pass 2: apply
        for c in range(1, cols):
            if matrix[r][0] == 0 or matrix[0][c] == 0:
                matrix[r][c] = 0

    if row0:                                 # pass 3: the borders themselves
        for c in range(cols): matrix[0][c] = 0
    if col0:
        for r in range(rows): matrix[r][0] = 0

Record first, apply second. If you zero cells while you are still scanning, the zeroes you just wrote look like original zeroes and cascade until the whole grid is blank.

Diagonals and layers

Cells on the same anti-diagonal share r + c; cells on the same main diagonal share r − c. Walking "layer by layer" is the spiral with the four sides collected together instead of appended in order.

Common mistakes

Transposing the whole square. for c in range(n) swaps each pair twice and leaves the matrix unchanged. The inner loop starts at r + 1.
Reversing the wrong axis. Transpose + reverse rows is clockwise. Transpose + reverse columns is counter-clockwise. Try it on the 3 × 3 above if you are unsure.
Dropping the spiral guards. On a single leftover row or column the third and fourth loops revisit cells. The guards are not optional.
Zeroing as you scan. Freshly written zeroes are indistinguishable from originals, so they cascade. Two passes: mark, then apply.
Assuming square. Use len(matrix) and len(matrix[0]) separately, and check for an empty matrix before touching matrix[0].

Complexity

  • Time: O(rows × cols) for all three techniques. Every cell is read or written a constant number of times.
  • Space: O(1) beyond the output. Rotation and zeroing are in place; the spiral only allocates the list it returns.
